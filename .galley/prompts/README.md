# 어투 프롬프트

`velog.md` · `linkedin.md` · `zenn.md` — 벨로그 본문·링크드인 요약·Zenn 일본어판 단계가 **파일 내용을 그대로** 모델 프롬프트에 붙인다. 그래서 이 폴더의 세 파일에는 어투 지시만 두고, 설명·메모는 여기 README에 둔다(주석도 모델에 간다).

- 사람이 에디터로 고치고 git이 이력을 갖는다. 저장소를 DB로 바꾸지 않는다 — decisions/tone-prompts.md.
- 파일 내용의 sha256이 그 단계의 `RunStep.promptHash`에 남는다. 같은 주제의 시도 사이에 결과가 달라졌을 때 "어투가 바뀌었다"를 판별하는 용도이고 화면에는 나오지 않는다. 앞뒤 공백·끝 개행도 내용이다(prettier가 이 폴더를 건드리지 않는 이유).
- 파일이 없거나 비어 있으면 그 단계는 실패한다(재시도 없음). 기본 어투를 코드에 두지 않는다.
- 폴더 위치: `.env`의 `PROMPTS_DIR`(절대경로)이 있으면 그것, 없으면 이 폴더.
- 링크 자리 토큰(`linkedin.md`의 `[벨로그 링크]`, `zenn.md`의 `[velogリンク]`)은 코드의 SYSTEM 머리와 **짝**이다 — 어투에서 토큰명을 바꾸면 `packages/pipeline/src/steps/{linkedinStep,zennStep}.ts`의 문구도 같이 바꾼다(코드는 토큰 존재를 검사하지 않는다).
- 세 파일은 사용자의 어투 프롬프트(2026-09-22)에서 왔다: 공통 규칙 + 채널 블록 하나씩. 원본의 "사용법" 메모와 코드 펜스는 뺐다(모델 입력에 불필요).

## 출고 전 체크(사람용 — 모델 입력 아님)

□ 벨로그: -요/-습니다가 인용문 밖에 남아 있지 않은가
□ 벨로그: 첫 문단이 "이 글에서는"으로 시작하지 않는가
□ 벨로그: 마지막 문장이 "X는 A가 아니라 B였다" 한 줄로 끝나는가
□ 링크드인: 해시태그·이모지·느낌표 0개인가, `글: [벨로그 링크]`로 끝나는가
□ Zenn: 「はじめに」「まとめ」가 있는가, 실명·회사명·링크가 없는가
□ 공통: 회사 고유 경로·필드명이 일반 이름으로 바뀌었는가
□ 공통: 확인 안 된 수치·이유에 [확인 필요] 주석이 붙어 있는가
