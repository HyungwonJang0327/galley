# galley-ui

A small React design system for desktop admin tools: design tokens (light + dark), headless wrapper
primitives on top of [Base UI](https://base-ui.com), layout patterns, and promise-based dialog hooks.
Styling is CSS Modules plus CSS custom properties only — no runtime CSS-in-JS, no Tailwind.


```tsx

```

## Principles

- **Controlled only.** Inputs take `value` / `checked` and `onValueChange` / `onCheckedChange`; the
  component never owns form state.
- **Tokens, not literals.** Colors, spacing, type, radii, shadows, motion and dimensions are `--ui-*`
  custom properties. Override them on `:root` to retheme; switch dark mode with
  `<html data-theme="dark">` — try the **Theme** toolbar above.
- **Thin wrappers.** Primitives keep Base UI's prop names and document the behavior you might trip on.
- **Domain-agnostic.** No business words in props, defaults or docs.
- **Accessible by default.** Live regions, focus handling and names are part of each component; the
  **Accessibility** panel below each story runs axe.
