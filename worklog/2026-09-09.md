## Dialog·Select 프리미티브 — UM1

### 참여

### 논의·결정

- **Base UI 패키지명 변경 발견**: 결정 문서의 `@base-ui-components/react`는 1.0.0-rc.0에서 정지, 현행은 **`@base-ui/react` 1.8.0**(2026-09-04). 서브패스 import(`/dialog`·`/select`). base-ui-over-shadcn 갱신 이력에 기록. `@galley/ui` `dependencies`(정확 핀) + Vite `external`(소비자가 한 벌만). lucide-react 1.43.0 같이 설치(Dialog ×·Select chevron·check).
- **`"use client"` 보존(사용자 결정)**: Rollup이 지시어를 버리므로 `output.banner`로 번들 전체(ESM·CJS)에 1줄. 전부 클라이언트 컴포넌트가 되지만 SSR HTML 불변·로컬 도구라 비용 작음. 파일별 보존(`preserveModules`+플러그인)은 npm 배포 시점 재검토 — ui-package-boundary에 확정 기록. 빌드 산출물 첫 줄 `"use client";` 확인, Base UI 미번들 확인.
- **Dialog**(`e8ed197`): 제어형만(`open`·`onOpenChange`), `title`=접근성 이름(Base UI가 aria-labelledby), `description`·`children`·`footer` 슬롯, `trigger`는 Base UI `render` 주입, `closeLabel`(기본 '닫기'). 포커스 트랩·Esc·바깥 클릭은 Base UI modal 기본값. `await` 패턴 훅은 YAGNI. 토큰 3개 추가(`--ui-color-backdrop`·`--ui-dialog-width` 480·`--ui-control-height` 32).
- **Select**(`6c471b4`): 단일 선택 제어형. `items: { value, label, description?, trailing?, disabled?, disabledReason? }` — model-selection의 "label + provider 보조 + 우측 단가 회색"을 앱이 `description`·`trailing`으로 채움. `disabledReason`은 Tooltip 프리미티브 전이라 native `title`. Root `items`에 `{value,label}` 배열을 넘겨 `Select.Value`가 label을 자동 표시. `alignItemWithTrigger={false}`(목록이 트리거 아래로).
- **테스트 함정**: Base UI Item은 트리거를 연 press의 잔여 `click`을 거르므로(`allowMouseSelectionRef`) `fireEvent.click`만으로는 선택이 안 됨 → 실제 순서대로 `pointerDown` → `click`. happy-dom에서 Dialog·Select 팝업 모두 정상 렌더(jsdom 전환 불필요).
