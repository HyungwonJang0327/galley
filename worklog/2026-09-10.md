### 논의·결정

- **전제 표명**: 스펙의 "MenuItem도 공통 ItemContent"는 Menu 프리미티브가 아직 없어(UM1은 Dialog·Select) **ItemContent만 분리**하고 Menu(UM2, AN5 선행)가 생길 때 소비하도록 todo에 걸어 둠. 사용자에게 Menu까지 지금 만들지 확인 요청.
- **원인**: 팝업 폭이 `min-width: var(--anchor-width)`만 있고 `width`가 없어 트리거 폭에 묶였고, 보조 텍스트에 nowrap이 없어 좁은 열에서 한 글자씩 세로 줄바꿈.
- **수정**(`packages/ui`): Popup `width: max-content; min-width: var(--anchor-width); max-width: var(--ui-select-popup-max-width)`(토큰 `min(480px, calc(100vw - var(--ui-space-6)))`). Positioner는 위치만. 공통 **`ItemContent`**(`primitives/ItemContent/`, 배럴 비노출 — Select·Menu 내부용): `[본문 열: 라벨(line-clamp 2) / 보조(한 줄 ellipsis)] + [우측 메타(shrink 0·margin-left auto·tabular-nums)]`. `label`은 ReactNode라 `Select.ItemText`로 감싼다(타입어헤드·접근성 유지). SelectItem `trailing`→**`meta`** 개명(갤러리 데모 동반 수정).
- **스토리**: 라벨만 / 라벨+보조 / 라벨+보조+메타 / 긴 라벨(40자)+긴 보조 / 화면 하단(decorator로 100vh 하단 정렬). 갤러리에도 같은 5케이스(하단은 페이지 마지막 카드).
- **실측(CDP 스크립트 `verify-select.mjs`, 스크래치패드)**: 5케이스 전부 PASS — 라벨만 160→160(트리거보다 좁아지지 않음) · 메타 160→186 · 긴 라벨 471→480(상한) · 라벨 ≤ 2줄 · 보조 1줄+ellipsis · 메타 폭 유지 · 화면 하단 popup.bottom(728) ≤ trigger.top(732) 뒤집힘. 스크린샷 확인.
- **측정 함정**: Base UI는 닫히는 팝업을 exit 애니메이션 동안 DOM에 남긴다 → `document.querySelector('[role=listbox]')`가 잔여 노드를 잡아 0px로 측정됨. 트리거 `aria-controls`로 listbox를 찾고, 닫힌 뒤 사라질 때까지 기다리도록 수정.
- `JSX.Element`는 React 19 타입에서 전역이 아님 → 스토리 decorator 타입은 `ReactElement`.
