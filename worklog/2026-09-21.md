## P4-7 Skeleton — feat/ui-skeleton

참여: 메인 에이전트(구현) · reviewer(리뷰) · 사용자(결정).

### 구현 (커밋 3)

- 판정: **직접 작성** — Base UI 1.8.0에 Skeleton 서브패스 없음.
- `3cad089` feat(ui): `components/Skeleton/` 5파일 + 배럴(`Skeleton`·`SkeletonProps`·`SkeletonRadius`·`SkeletonSize`). `width`/`height`(숫자=px, 문자열=CSS 값) · `radius` sm|md|full · `lines`(2 이상이면 span 막대를 쌓고 마지막 줄 60% — width가 있으면 `calc(w * 0.6)`) · `aria-hidden` 기본. 색 `--ui-color-border` 재사용(전용 색 토큰 없음). 펄스 1.5s + `prefers-reduced-motion`에서 없음.
- `20b29a4` feat(dashboard): 갤러리 섹션(`data-demo` skeleton-shapes·lines·card).
- `21239d5` test(dashboard): `skeleton.mjs` 13검사(186→199).
- 라이트·다크 스크린샷 육안 확인 — 다크는 막대가 옅음(reviewer에 판단 요청).

### 리뷰 — high 0 · med 3 · low 8 → 사용자 "L4만 빼고 추천대로"

- **M1** `.bar`의 `flex-shrink: 0` + `width: 100%` — 폭 없는 막대가 flex 행에서 넘친다(Separator L3와 같은 패턴) → 제거, 폭을 준 막대만 인라인 `flexShrink: 0`. 갤러리 flex 행 시연 + 실측 3검사 `4a476af`
- **M2** "부모가 aria-busy로 알린다"는 부정확 — aria-busy는 낭독 보류 힌트일 뿐 아무것도 읽히지 않는다 → JSDoc·스토리·갤러리를 "aria-busy(보류) + 그 **밖**의 상시 `role="status"` 시각 숨김 텍스트"로 정정 `702aee9`. status 텍스트를 Skeleton API에 넣지 않고 소비자 규칙으로(사용자 승인). VoiceOver 실측은 todo P7h에 얹음.
- **M3** `aria-hidden={undefined}`를 명시로 넘기면 기본이 지워짐 → 스프레드 뒤 `?? true` + 회귀 테스트 `eee163c`
- **L1** 숫자→px는 스펙 밖·선례 없음 → 유지하되 JSDoc "토큰 우선, 숫자는 토큰에 없는 치수만" + 갤러리 문구 `5a8e7d8`(flex 행 데모는 `var(--ui-space-5)` 사용)
- **L2** 단일 모드 루트 div → **span**(display:block) 통일 — 텍스트 안에서도 유효한 중첩 `6b80a89`
- **L3** 테스트 누락 → 여러 줄 radius·루트 인라인 없음·문자열 width calc 3건 `7029dbf`(M3·aria-hidden 해제는 각 커밋에)
- **L4 다크 옅음** — reviewer: 수치상 다크 고유 문제 아님(surface 대비 라이트 1.24 / 다크 1.23, 펄스 최저 둘 다 1.10), 장식이라 WCAG 비대상, 추천은 현행 유지. **사용자: 갤러리에서 직접 비교** 요청 → 임시로 "0.45·0.6 최저점 정지 + 실제 펄스" 4개를 나란히 넣고 스크린샷. 에이전트 소견: 0.45는 최저점에서 표면과 거의 구분 안 됨(사라지는 느낌), 0.6은 형태가 남음. **사용자 결정: 0.6** `6e50ac5`. 임시 비교 데모는 커밋하지 않고 제거.
- **L5** 스토리 카드 폭 `--ui-dialog-width` 차용 → 제거 `99e5c0a`
- **L6** prop `full` ↔ 토큰 `pill` 어휘 → RF1 입력에 기록만. **L7** Badge 펄스에 reduced-motion 없음 → RF1 입력 ②에 추가. **L8** 실측 스크립트의 DOM 결합 → 관례, 조치 없음.

### 발견 — 리뷰 반영이 만든 회귀 2건(실측이 잡음)

- M2의 시각 숨김 `role="status"` span(`position: absolute`)이 안쪽 스크롤 영역에서 **body를 늘려** 셸 실측 4건 실패(FormField hidden input 때와 같은 함정). 위치 기준 부모 `.loadingWrap`(relative) 추가 `f1218ce`.
- M1의 flex 행 데모에서 폭 없는 Skeleton(100% 요구)이 형제 버튼을 눌러 "버/튼"으로 접힘 → 버튼 `flex-shrink: 0`(같은 커밋). 폭 없는 Skeleton은 100%-폭 요소와 같아 형제가 눌린다 — 소비자 책임.
