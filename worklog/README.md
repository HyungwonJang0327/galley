# worklog/

**오늘 무엇을 했나**(일지). 확정 목록은 `planning.md`, 맥락은 `decisions/`.

## 규칙

- 날짜별 파일 `worklog/YYYY-MM-DD.md`. 날짜는 `date +%Y-%m-%d`로 확인.
- `/log`가 이전 `/log` 이후 대화만 분석해 기록(파일 있으면 이어 붙임).
- 각 항목: **참여 에이전트 / 논의 내용(누가 어떤 의견) / 결론·결정 / 미결·다음**.
- 확정 사항은 `decisions/`에 병합(덮어쓰기 금지, 충돌 시 "⚠️ 결정 변경 확인 필요"), planning 체크 갱신, todo 완료 항목에 날짜·해시.
